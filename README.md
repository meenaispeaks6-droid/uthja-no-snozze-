# ⏰ LUNE — Gen Z Anti-Snooze Alarm (Android)

A Gen Z-focused alarm app that actually gets you out of bed. Dismiss the alarm by completing challenges — shake your phone, solve math problems, or type to prove you're really awake.

## Features

- 🧠 Anti-snooze dismiss challenges (shake, math, typing)
- 😴 Sleep tracking and wake-up insights
- 🌙 Calm, minimal, night-friendly design
- 📊 Intentional morning routines & habit tracking

## Tech Stack

- Kotlin (native Android)

## Build

Open the project in Android Studio and run on an emulator or device.
